Module scope

Register first. Inspect against one persistent record.

Register creation

Create a usable door register manually where needed, without waiting for a perfect source dataset.

Door history

Keep inspections, defects, remedial actions and decisions on the same Door Object.

Sectors and checks

Structure the inspection so required checks are visible and tied to the correct door.

Evidence and sign-off

Attach photos, defect records, completion evidence and human sign-off to the history.

Shared logic

DoorSuite and the register share Door Object thinking.

The inspection demonstrator can use the same persistent door identity and evidence pattern as DoorSuite without pretending both applications are already one finished production system.

Product boundary

This is not presented as a production compliance platform.
