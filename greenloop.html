R&D / pilot development

GreenLoop.

A controlled circular-material track focused on selected clean polymer streams, practical reprocessing and useful manufactured outputs rather than mixed or heavily contaminated waste.

Material pipelineDiscuss a material stream
PriorityClean TPU production waste and other identifiable B2B polymer streams.
PolymersTPU, PP, HDPE and ABS where material identity and process compatibility are controlled.
OutputsGranulate, extrusion trials, filament, simple parts and formed products.

Material pipeline

Source → Sort → Process → Granulate → Extrude → Print / Form → Reuse.

Each batch should retain traceable material identity and process history.

01 SOURCEKnown clean B2B feedstock.
02 SORTSeparate material and reject unsuitable feed.
03 PROCESSClean, shred and dry.
04 GRANULATEPrepare repeatable feedstock.
05 EXTRUDEControlled extrusion trials.
06 PRINT / FORMMake useful test parts.
07 REUSEReturn material value to a practical application.

TPU streams

Current priority includes clean TPU production waste where source, contamination and supply consistency can be verified.

PP / HDPE / ABS

Use identifiable material streams with enough consistency for meaningful process control.

Manufactured outputs

Start with granulate, filament, prototypes, fixtures and simple formed parts before demanding applications.

Feedstock rule: GreenLoop is not positioned around random dirty waste. The preferred starting point is a known, clean and traceable material stream.
