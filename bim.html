NOSMO Nexus · BIM module

Development direction

NOSMO BIM.

The BIM module connects models and object identities to project context, people, documents, evidence, decisions and asset history. It is separate from WorkSuite.

BIM capabilitiesNexus CoreWorkSuite applications

A model is the spatial reference. Nexus connects the context and history around it.

Connected model chain

Model → object → project context → evidence → asset history.

BIM remains the model and object layer. Trade applications can use those references through Nexus without becoming part of the BIM module.

BIM capabilities

Connect the model without pretending to replace authoring tools.

Model / object graph

Maintain relationships between models, objects, locations, systems and Nexus project records.

Coordination context

Connect issues, readiness, documents and decisions to the right object or spatial reference.

Field-to-model evidence

Return controlled evidence and status to the correct object identity without overwriting the source model.

Handover / digital twin direction

Build a traceable asset history for later operation, maintenance, replacement and reuse.
