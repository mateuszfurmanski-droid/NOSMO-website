# Relationship Tree repair — 2026-10-30

- The existing connection handle now opens an accessible picker with search,
  explicit save, existing-link feedback and removal of user-created links.
- Links remain browser-local. Storage is scoped by Project World. The legacy
  Riverside copy is read only as a fallback and retained for recovery.
- Stage labels were noninteractive spans. They are now buttons and a keyboard-
  accessible slider. They highlight related objects in the existing graph.
  Phase assignments are explicitly demo mappings, not verified schedules.
- Removed the nonfunctional volume/channel knob and simulated recording controls.
- Pointer updates are coalesced per animation frame; drag has no endpoint tween
  or release inertia; ordinary transitions are 180 ms instead of one second.
  Touch movement threshold is 12 px instead of 4 px. Root uses available height
  instead of an additional full viewport and scaled outer wrapper.

The shipped graph was present only in a compiled bundle. A narrowly anchored,
checked transformation is retained in scripts/repair-relationship-tree-20261030.py;
no other component is rewritten. Re-run only against the pre-repair bundle.
The normal product-source build should eventually replace this archived preview.

Automated validation: syntax checks and tests/relationship-tree-repair.test.cjs.
Live browser checks are required after deployment. No measured FPS claim.
